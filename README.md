# C++ Network Programming

A compact POSIX TCP networking example demonstrating socket-based client/server communication.

## Features
- TCP socket creation and binding
- Listening and accepting connections
- Basic request/response handling
- Portable C++ structure with clear error handling

## Build
```bash
mkdir build && cd build
cmake ..
cmake --build .
```

## Run
Start the server, then connect with a TCP client such as `nc`.

> This project is a personal portfolio example for learning and demonstrating systems/network programming concepts.
